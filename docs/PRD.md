# Product Requirement Document (PRD)

## Product Name
5-Minute Daily Planning App

## Goal
사용자가 하루에 단 5분만 투자하여 다음 루틴으로 하루 계획을 세울 수 있도록 돕는다.

1. Brain Dump (2분)
2. Big 3 선택
3. 예상 시간 입력
4. 하루 계획 확인
5. 하루 회고 작성

핵심 철학은 **많은 계획보다 중요한 3가지에 집중하는 것**이다.

## Target User
- 개인 시간 관리가 필요한 사람
- 학생, 개발자, 창작자
- 복잡한 생산성 앱을 부담스러워하는 사용자

## Core Concept
이 앱은 일정 관리 앱이 아니라 **생각 정리 + 우선순위 결정 + 하루 기록 앱**이다.

## Core Features

### 1. Brain Dump
- 오늘 해야 할 일이나 떠오르는 생각을 자유롭게 입력
- 2분 타이머 제공

### 2. Big 3 Selection
- Brain Dump 목록에서 정확히 3개 선택

### 3. Estimated Time
- 선택된 Big 3 각각에 예상 시간 입력

### 4. Today Plan
- 오늘의 Big 3
- 예상 시간
- 완료 체크

### 5. Daily Review
- 하루 회고 메모 작성

### 6. History
- 날짜별 기록 조회

## Non Goals (MVP 제외)
- 로그인
- 팀 기능
- 알림 시스템
- 복잡한 캘린더
- 시간표 기능
- 통계 차트

## Success Criteria
- 사용자가 5분 안에 하루 계획을 세울 수 있다
- 하루 계획 + 회고 기록이 쌓인다
